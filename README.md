# Proyek Evaluasi Pekan 6 - JavaScript

## 1. Deskripsi Proyek

Proyek ini dibuat untuk menerapkan materi JavaScript, mulai dari pengolahan data transaksi, pembersihan data, mesin kasir, laporan harian, perbaikan kode, hingga eksperimen JavaScript. Proyek ini juga menggunakan Git dan GitHub untuk mengelola perubahan kode.

### Cara Menjalankan

1. Buka folder proyek di Visual Studio Code.
2. Buka file HTML yang tersedia menggunakan browser.
3. Untuk menjalankan file JavaScript melalui terminal, buka terminal di folder proyek.
4. Jalankan perintah berikut sesuai nama file:

```bash
node script.js
node perbaikan.js
node eksperimen.js
```

**Catatan:** Jalankan perintah hanya untuk file yang tersedia di proyek. Jika file JavaScript terhubung ke halaman HTML, buka file HTML tersebut melalui browser untuk melihat hasilnya.

### Teknologi yang Digunakan

- **HTML** — untuk membuat struktur halaman web.
- **JavaScript** — untuk mengolah data, membuat fungsi, menghitung transaksi, dan menjalankan eksperimen.
- **Git** — untuk mencatat perubahan dan mengelola branch.
- **GitHub** — untuk menyimpan repository secara online.
- **Visual Studio Code** — untuk menulis dan mengedit kode.
